Sample RAG Project
I built a RAG chatbot over my own documents using Streamlit, Milvus and Llama 3.2 3B on Ollama, and deployed it on AWS EC2 with Docker Compose behind a Caddy reverse proxy with HTTPS. For retrieval I used hybrid search, combining vector similarity with keyword matching, plus a score boost for chunks containing email addresses, because pure vector search kept missing exact values like emails and certificate numbers. I constrained the prompt so the model answers only from the retrieved context and says the information isn’t available otherwise.

For reliability, I dealt with real deployment problems: a MinIO image that was no longer pullable, which I solved by switching Milvus to embedded etcd and local storage, plus file permission issues and security group configuration. To measure quality, I’m building a golden set of questions with known answers and tracking recall@10, answer accuracy and p95 latency, and I’m comparing vector-only against hybrid search.
